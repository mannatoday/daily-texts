如何把這個網站變成手機 App？How do I turn this website into a phone app?

為了方便每天家庭靈修時快速打開，建議你將它設定到手機桌面上。Add it to the home screen so the family devotion is quick to open each day.

你已經從主頁的圖示打開。You already opened this from the home-screen icon.

這個瀏覽器可以直接安裝，按下面的按鈕即可。This browser can install it directly.

蘋果手機（iPhone / Safari）iPhone (Safari)

  1. 用 Safari 瀏覽器打開這個網址。Open this site in Safari.

  2. 點擊畫面下方的「分享」圖示（一個正方形帶有向上箭頭）。Tap the Share icon at the bottom of the screen (a square with an arrow pointing up).

  3. 往下滑動，選擇「加入主畫面」（Add to Home Screen）。Scroll down and choose “Add to Home Screen”.

  4. 命名為「摩拉維亞每日箴言」，點擊右上角「新增」即可。Name it 摩拉維亞每日箴言, then tap Add at the top right.

安卓手機（Android / Chrome）Android (Chrome)

  1. 用 Chrome 瀏覽器打開這個網址。Open this site in Chrome.

  2. 點擊右上角的「三個點」功能選單。Tap the three-dot menu at the top right.

  3. 選擇「安裝應用程式」或「加入主畫面」。Choose “Install app” or “Add to Home screen”.

  4. 確認後，手機桌面就會出現一個像 App 一樣的快捷圖示。After you confirm, a shortcut that looks like an app appears on the home screen.
