# GitHub Pages site

Generated by `StaticSitePublisher` when `PUBLISHERS` includes `static_site`.

- `index.html` — Chinese home: today’s card (via `today.html`) + recent 3 days + link to archive
- `en/index.html` — English home (canonical URL `/en/`)
- `today.html` — stable Chinese URL; copy of the newest `{YYYY-MM-DD}.html`, canonical points at that dated page
- `en/today.html` — same for English; canonical points at `en/{YYYY-MM-DD}.html`
- `archive.html` / `en/archive.html` — full day archive
- `{YYYY-MM-DD}.html` — Chinese day page (prev/next). This path is what daily publish checks.
- `en/{YYYY-MM-DD}.html` — English day page, verse text in the HTML
- `about.html` / `en/about.html` — about Moravian Daily Texts
- `sitemap.xml` — both languages (home, about, archive, dated days). `today.html` is omitted.
- Old `?lang=en` / `?version=NIV` links redirect in the browser to the `/en/` page.
- `robots.txt` — points crawlers at `sitemap.xml`
- `styles.css` — shared reading stylesheet (incl. dark mode & print)
- `version.js` — bible version picker (on-page watchword text)

## Deploy

**Preferred:** [`.github/workflows/daily-publish.yml`](../.github/workflows/daily-publish.yml) runs on a schedule (and manually), regenerates `site/`, and pushes to `master`. Pages then deploy via [`.github/workflows/pages.yml`](../.github/workflows/pages.yml).

**Manual / local:**

1. In the GitHub repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. Run fetch with static site enabled, then commit and push `site/`:

```bash
PUBLISHERS=static_site daily-texts fetch --force
git add site/
git commit -m "Update daily texts site"
git push origin master
```
