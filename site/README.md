# GitHub Pages site

Generated by `StaticSitePublisher` when `PUBLISHERS` includes `static_site`.

- `index.html` — today’s card (via `today.html`) + recent 3 days + link to archive
- `today.html` — redirects to Pacific-calendar `{YYYY-MM-DD}.html` (`America/Los_Angeles`); if that day is not published yet, falls back to the newest day page on the site
- `archive.html` — full day archive
- `{YYYY-MM-DD}.html` — one page per day (prev/next, footer, about blurb)
- `about.html` — about Moravian Daily Texts / this Chinese edition
- `styles.css` — shared reading stylesheet (incl. dark mode & print)
- `version.js` — bible version picker (on-page watchword text)

## Deploy

**Preferred:** [`.github/workflows/daily-publish.yml`](../.github/workflows/daily-publish.yml) runs on a schedule (and manually), regenerates `site/`, and pushes to `master`. Pages then deploy via [`.github/workflows/pages.yml`](../.github/workflows/pages.yml).

**Manual / local:**

1. In the GitHub repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. Run fetch with static site enabled, then commit and push `site/`:

```bash
PUBLISHERS=static_site daily-texts fetch --force
git add site/
git commit -m "Update daily texts site"
git push origin master
```
