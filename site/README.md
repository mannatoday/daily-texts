# GitHub Pages site

Generated by `StaticSitePublisher` when `PUBLISHERS` includes `static_site`.

- `{YYYY-MM-DD}.html` — one page per day
- `index.html` — newest-first list of days

## Deploy

1. In the GitHub repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. Locally run fetch with static site enabled, then commit and push `site/`:

```bash
PUBLISHERS=static_site daily-texts fetch --force
git add site/
git commit -m "Update daily texts site"
git push
```

The workflow [`.github/workflows/pages.yml`](../.github/workflows/pages.yml) deploys this directory on push to `master`.
